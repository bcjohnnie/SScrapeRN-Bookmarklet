SScrapeRN: SSRN papers to CSV

Build 2026-11-03 · 7f518a4 (shown in the panel's header). Nothing to install: this is a bookmark that runs on an SSRN page.

1. Add the bookmark

Show your bookmarks bar (Ctrl+Shift+B on Windows, Cmd+Shift+B on Mac), then drag this button onto it:

SScrapeRN

What the panel does

SScrapeRN only reads what an SSRN page already shows. It sends no requests to SSRN and clicks nothing on SSRN's page, so it does nothing a person reading the page doesn't. The panel offers, in order:

  • Archive this profile… (recommended): a whole folder with the papers (CSV and JSON), a copy of the page, a README and a checklist for downloading the PDFs yourself. Use this to preserve a profile.
  • Download papers CSV: just the spreadsheet of every paper on the page, straight to Downloads.
  • Download tracking (optional): one spreadsheet you keep that records each paper's download and citation counts every time you run it.

2. Before you click anything in the panel

  1. Open an SSRN author page (papers.ssrn.com/sol3/cf_dev/AbsByAuth.cfm?per_id=…) or a research paper series page (www.ssrn.com/index.cfm/en/…).
  2. Above the paper list, click SSRN's All Versions (if it's there) and All Abstracts. Wait until the abstracts show under the papers. (SSRN counts these as abstract views, as it does for anyone who clicks them.) If you skip either, the panel warns you before saving anything.
  3. Click the bookmark. A panel opens at the top right.

3. Archive this profile (recommended)

Click Archive this profile… and choose a folder (Chrome or Edge; other browsers save the files to Downloads). It writes a folder named ssrn_author_<id>_<name> with:

  • the papers as CSV and JSON (abstracts, keywords, links, co-author profile links);
  • a copy of the page, and a README saying when it was captured;
  • download-checklist.html: every paper, linked to its SSRN page, marked To download, Saved, Sold by SSRN or No PDF on SSRN;
  • an empty pdfs folder for the PDFs you download.

Downloading the PDFs is up to you, by hand. Open the checklist, click each title marked To download, click SSRN's Download This Paper, and save the PDF into the archive's pdfs folder. Keep the file name SSRN gives it: it contains the paper's ID, which is how files are matched to papers. Go at your own pace, and consider asking the authors first: SSRN counts each one as a download of that paper.

Then, from any SSRN page, click the bookmark, click Check downloaded PDFs… and pick the archive folder. The checklist and manifest_<date>.csv are rewritten to show which papers have a PDF and which are still to download. Check as often as you like; it reads only your folder.

Archiving the same profile again later (into the same place) refreshes the metadata and keeps the PDFs already saved.

4. Papers list (CSV only)

Click Download papers CSV for just the spreadsheet, saved straight to Downloads. It has the same columns as the archive's papers file. Keywords, PDF links and what SSRN offers for each paper (free PDF, no PDF, or sold) are read from the page. DOIs aren't included: SSRN shows them only on each paper's own page. Series pages show 50 papers at a time: export each page and combine the files.

5. Download tracking (optional)

This builds one spreadsheet of each paper's download and citation counts over time: a row per paper per date you run it. It lives in a file you keep; nothing is stored in the browser. (The archive already records today's counts, so you only need this to follow them over months.)

  1. The first time, click First time? Start a history file. It saves …_ssrn_download_history_<date>.csv with today's counts.
  2. Each later time (monthly, say), click Add today's counts to my history file… and pick the newest of those files. It saves a new copy, named with today's date, holding everything from before plus today's counts. Keep the newest copy; the older ones can be deleted.

One history file can follow several authors: pick the same file on each author's page. Running it twice on the same day replaces that day's counts rather than adding a second row. A history file exported from the SScrapeRN browser extension can be picked too.
